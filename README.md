# ISTQB® CTFL® v4.0 Sınav Hazırlığı

Ücretsiz CTFL v4.0 sınav rehberi ve beş deneme sınavı. Konuları çalışın, denemelerle pratik yapın ve eksiklerinize dönün. Resmî kaynaklara bağlantılar.

Bağımsız hazırlık kaynaklarıdır; ISTQB® veya Turkish Testing Board ile bağlantılı değildir ve bu kurumlar tarafından onaylanmamıştır. ISTQB® ve CTFL®, ISTQB’nin tescilli markalarıdır.
